# Startup Ideas Tracker

## Описание
Startup Ideas Tracker — это iOS-приложение для сохранения, оценки и отслеживания идей стартапов. Оно помогает предпринимателям не забыть важные мысли, структурировать их и оценивать потенциал.

## Основные функции
- **Список идей**: Просмотр всех сохраненных идей.
- **Детальный экран**: Просмотр полной информации об идее (проблема, решение, аудитория, монетизация).
- **Добавление идеи**: Заполнение формы с бизнес-моделью и оценкой идеи, а также функция генерации вдохновения по сети.
- **Избранное**: Возможность отмечать лучшие идеи (через детальный экран).
- **Поиск**: Быстрая фильтрация списка идей по названию и проблеме.
- **Поделиться**: Возможность поделиться идеей текстом через нативный Share Sheet.
- **Локальное хранение**: Все данные сохраняются на устройстве.

## Архитектура
Приложение построено с использованием паттерна **MVVM + Observation**:
- **ViewModel** (`StartupListViewModel`) отвечает за бизнес-логику, поиск и состояние экрана (`ViewState`: loading, empty, content, error).
- **View** отвечает исключительно за отображение данных.
- **Service-слой** и **Storage-слой** изолированы протоколами (`StartupStorageService`, `NetworkServiceProtocol`) и внедряются через Dependency Injection, что позволяет легко подменять их на моки при тестировании.

## Используемые технологии
- **UI**: SwiftUI
- **Архитектура**: MVVM + Observation
- **Навигация**: NavigationStack
- **Локальное хранилище**: SwiftData (выделено в отдельный SPM пакет `StorageKit`)
- **Сеть**: URLSession + async/await + Codable
- **Concurrency**: `Task`, `async/await`, `@MainActor`
- **UIKit Integration**: `UIViewControllerRepresentable` (ShareSheet на базе `UIActivityViewController`)
- **Менеджер зависимостей**: Swift Package Manager (SPM)

## Как запустить проект
1. Откройте файл `Startup Ideas Tracker.xcodeproj` в Xcode.
2. Выберите симулятор (например, iPhone 15 Pro) или реальное устройство.
3. Нажмите `Cmd + R` (или кнопку Run) для запуска приложения.
(Подключение сторонних пакетов происходит автоматически локально через `StorageKit`).

## Как запустить тесты
1. Откройте проект в Xcode.
2. Выберите таргет `Startup Ideas TrackerTests`.
3. Нажмите `Cmd + U` (или меню Product -> Test), чтобы запустить весь набор Unit-тестов.
Тесты покрывают успешную загрузку, обработку ошибок, пустые состояния списка и логику фильтрации поиска.
